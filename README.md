## About This Project
PrimeCare is a fully functional Clinic Management 
System developed as an original academic project 
for Diploma in ICT. The system manages patients, 
appointments, consultations, billing and reports.

## Technologies Used
- PHP 8.2
- MySQL 8.0
- Bootstrap 5.3
- Chart.js
- XAMPP

## System Modules
- Login & Authentication
- Dashboard & Analytics
- Patient Management
- Appointment Booking
- Consultations & Diagnosis
- Billing & Invoicing
- Doctors Management
- Reports & Analytics
- Admin Panel
